# Security

Kill Chain is a local Windows desktop application. It does not collect account data or send your audio to a cloud service as part of normal operation.

## Reporting a vulnerability

If you believe you've found a security issue, please **do not** open a public issue with exploit details.

Instead, open a [GitHub Issue](https://github.com/JerryKoller/Kill-Chain/issues/new/choose) and select the closest template, or describe the concern privately in general terms and ask for a private contact method.

We will review reports as quickly as possible.
